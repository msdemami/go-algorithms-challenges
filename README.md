# Go Exercism Challenges

A collection of my solutions to intermediate-level algorithmic challenges from the [Exercism Go track](https://exercism.org/tracks/go), focused on writing clean, idiomatic Go.

## Key Learnings / Highlights

- **Idiomatic Go** — Emphasis on Go conventions, effective error handling, and clean code principles.
- **Problem-Solving** — Strengthened algorithmic thinking through diverse, real-world puzzles.
- **Test-Driven Development** — Every solution passes Exercism's strict unit tests, reinforcing a TDD workflow.

## Included Challenges

| Challenge | Topic |
|---|---|
| Hamming | String comparison & distance |
| Luhn | Validation algorithm |
| Collatz Conjecture | Mathematical sequences |

| Lasagna | Functions & basic arithmetic |

- **Testing:** `go test` with Exercism-provided test suites
